# ClearDQ v2 - Data Quality Management (Neutral & Slate theme, lucide icons)
Backend: cd backend && python -m venv venv && activate && pip install -r requirements.txt && uvicorn app.main:app --reload --port 8000
Frontend: cd frontend && npm install && npm run dev  -> http://localhost:5173
Default admin: admin@dqm.com / Admin@123 (choose "Administrator"). Analysts sign up themselves.
Forgot password shows the reset code on screen (demo mode).
